Ihr kennt alle das Interet mit seinen Webseiten, Gameservern und Streamingdiensten.
Aber das ist nur ein kleiner Teil des Internets. Es gibt noch sehr viel mehr Möglichkeiten Informationen im Internet zu verbreiten als die meisten Leute kennen.
Diese Schnitzeljagd führt euch durch die abgelegensten Teile des Internets bis ihr schließlich am Ziel ankommt und euch in die Bestenliste eintragen könnt.

Das Internet kennt viele verschiedene Protokolle. Diese kann man immer an dem Schlüsselwort am Beginn der Adresse, die man auch URL nennt erkennen. Zur Zeit benutzt ihr mit eurem Browser das HTTP-Protokoll. Wenn ihr in die Adresszeile doppelklickt, dann könnt ihr sehen das die URL mit https:// beginnt.
Das steht für Hypertext Transfer Protokoll Secure, also die verschlüsselte Version des HTTP Protokolls. Hypertext bedeutet das ihr hier eigentlich nur normalen Text angezeigt bekommt, aber manche Wörter (tags) sind spezielle “Hyperwörter”, die im Browser spezielle Funktionen starten z.B. einen anklickbaren Link oder ein Bild anzeigen oder einfach den Text formatieren wie fettdruck, kusiv oder unterstrichen.
Die Programmiersprache nennt sich HTML (Hypertext Markup language).
So weit so gut. Das ist das normale Internet bzw www (world wide web) das jeder kennt. Vielleicht sind euch aber schon andere Schlüsselworte als http:// oder https:// begegnet.
Dieses Spiel wird euch quer über die ganze Welt von Server zu Server leiten, bis ihr am Ziel ankommt. Jeder dieser Server verwendet ein anderes Protokoll. Manches könnt ihr direkt in eurem Browser benutzen. Für viele andere müsst ihr zuerst einen Client installieren der dieses Protokoll versteht. Eure Aufgabe ist es anhand des Schlüsselworts herauszufinden um was für ein Protokoll es sich handelt und wie man sich mit einem solchen Server verbindet. Ihr dürft alles Benutzen was ihr wollt: google, KI, Bücher, eigenes Wissen,....

Auf vielen Servern müsst ihr euch anmelden. Die Zugangsdaten sind immer gleich:

Benutzername: DO1EH
Passwort: JOTAJOTI26

Achtet auf Groß und Kleinschreibung!

Allgemeiner Hinweis:
Für manche Protokolle gibt es einen Proxy oder ein Plugin, der das Protokoll im Browser aufrufbar macht. Nutzt diese bitte nicht, denn die Darstellung ist nicht sehr schön und verzerrt teilweise Text und Bilder. Nutzt am Besten immer einen entsprechenden Client oder Browser der das direkt kann. Nur dann habt ihr das echte Erlebnis, wie sich das damals angefühlt hat damit zu arbeiten.
BTW: Früher wäre diese Schnitzeljagd recht langweilig gewesen, denn Chrome, Firefox und andere Browser konnten standardmäßig alle diese Protokolle. Man musste nur z.B. ftp://xxxx in die Adresszeile eingeben. Mittlerweile gelten sie aber als unsicher, da sie sehr alt sind und Sicherheitskücken aufweisen. Deswegen wurden sie aus Sicherheitsgründen alle komplett aus den Browsern entfernt, so dass man heute für jedes Protokoll einen eigenen Client braucht.
